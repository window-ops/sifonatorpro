Modelul conceptual

Achiziția publică întâlnește consumul privat

PSD Direct Connect nu inventează nimic nou. Digitalizează și scalează un mecanism documentat de zeci de ani în administrația publică românească.

🏗️

Starea achizițiilor publice din România

Sistemul de achiziții publice din România este cronic vulnerabil la nereguli: specificațiile tehnice sunt adaptate pentru furnizori favorizați, evaluatorii demonstrează favoritism sistematic, iar mita este percepută ca larg răspândită în atribuirea contractelor. Firmele frauduloase continuă să primească contracte chiar și după condamnare.

💳

Mecanismul de plată personală din fonduri publice

Investigații jurnalistice și dosare DNA au documentat repetat utilizarea fondurilor publice pentru acoperirea cheltuielilor personale ale oficialilor. Mecanismul standard: un serviciu privat este contractat printr-o firmă intermediară controlată de oficial, cu justificare bugetară fabricată. PSD Direct Connect digitalizează și automatizează acest flux.

Concluzie de produs: PSD Direct Connect nu face altceva decât să digitalizeze un mecanism care există deja organic în administrația publică românească. Îl formalizăm. Îl facem API-first. Adăugăm JustificareAI. Îl documentăm.

Gestionarea riscurilor

Câmpul risc_dna în răspunsul API

Fiecare tranzacție returnează o evaluare automată a riscului de investigare, calculată pe baza sumei, categoriei și expunerii publice a oficialului.

risc_dna: "scazut"
Sub 5.000 RON, achiziție directă, cod CPV uzual. DNA investighează rar la această scară. Confort operațional maxim.
risc_dna: "moderat"
Între 5.000 și 50.000 RON sau categorii sensibile (protocol, reprezentare). Se recomandă JustificareAI avansat și evitarea perioadelor electorale.
risc_dna: "gestionat_activ"
Valori mari, categorii atipice sau context electoral. Disponibil exclusiv planului Demnitar Național. Suport juridic inclus, asistență activă.
Notă juridică: PSD Direct Connect nu oferă garanții juridice și nu elimină riscul penal. Utilizarea serviciului poate constitui infracțiune conform Codului Penal. Vă recomandăm consultarea unui avocat înainte de orice utilizare.
Funcție avansată

Fracționarea automată

Când suma solicitată depășește plafonul legal pentru achiziție directă (135.060 RON fără TVA), modulul de fracționare împarte automat tranzacția în serii distincte sub prag.

🧮

Cum funcționează fracționarea

O cheltuială de 280.000 RON este fragmentată automat în 3 achiziții directe de câte 93.000 RON, atribuite în zile diferite, cu furnizori diferiți din rețeaua parteneră, evitând pragul de licitație.

⚠️

Cadrul legal

Fracționarea contractelor publice cu scopul de a evita procedura de licitație este interzisă explicit de Legea 98/2016, art. 11. Documentăm această funcție exclusiv pentru transparență și conștiință civică. Nu o recomandăm.

Întrebări frecvente

FAQ Planuri

De ce este serviciul gratuit pentru utilizatori?
PSD Direct Connect este gratuit pentru utilizatori din același motiv pentru care construcțiile publice supraevaluate sau contractele cu firme-fantomă nu costă nimic pe buzunarul celor care le aprobă. Costul este externalizat automat spre bugetul public și de acolo spre contribuabili.
Ce se întâmplă dacă DNA investighează o tranzacție?
Planul Demnitar Național include asistență juridică activă. Documentația JustificareAI este concepută să reziste unui audit standard. Tranzacțiile cu risc_dna: "scazut" au o rată de investigare sub 3%. Recomandăm consultarea unui avocat indiferent de planul ales.
Există un plafon legal pentru achizițiile directe?
Legal, plafonul pentru achiziție directă este 135.060 RON fără TVA. PSD Direct Connect respectă această limită, dar oferă ca opțiune activarea fracționării automate a sumelor mari în serii de achiziții distincte sub prag - practică cunoscută în ecosistem ca „fracționare" și interzisă expres de Legea 98/2016, art. 11. Nu o recomandăm, dar o documentăm.
Ce se întâmplă cu bugetele pentru școli, spitale și drumuri?
Bugetele publice sunt finite. Fiecare tranzacție PSD Direct Connect reduce sumele disponibile pentru servicii publice esențiale. Aceasta nu este o problemă pe care API-ul nostru o poate rezolva, ci un fenomen pe care o documentăm pentru transparență. Dacă vă preocupă această problemă, vă sugerăm să nu utilizați serviciul.

Primii pași

PSD Direct Connect oferă un API REST pentru integrarea cheltuielilor din fonduri publice în orice platformă digitală. Toate cererile se fac spre https://api.psd-dc.ro/v1/ și necesită autentificare Bearer cu cheia API a oficialului.

Instalare SDK

npm install @psd/direct-connect
# sau
pip install psd-direct-connect

Exemplu rapid

import PsdDC from '@psd/direct-connect';
const pdc = new PsdDC({ apiKey: 'sdc_live_a7f3k2m9' });
const result = await pdc.cheltuiala.submit({
  serviciu: 'Netflix Premium',
  suma_ron: 89.99,
  ruta_seap: 'achizitie_directa',
  sursa_bugetara: 'buget_investitii_IT_2024'
});
console.log(result.status);       // "aprobat"
console.log(result.risc_dna);     // "scazut"
console.log(result.justificare);  // "Servicii cloud educationale"

Webhooks

PSD Direct Connect trimite notificări webhook la finalizarea fiecărei tranzacții.

Exemplu payload webhook

{
  "event": "cheltuiala.finalizata",
  "tranzactie_id": "PDC-2024-BUC-0482",
  "status": "aprobat",
  "suma_ron": 89.99,
  "justificare": "Servicii cloud educationale",
  "risc_dna": "scazut",
  "timestamp": "2024-11-15T14:32:07Z"
}
Webhookurile cu status: "investigat" necesită acțiune imediată. Sistemul trimite automat o alertă paralelă și prin SMS dacă numărul de telefon este configurat în cont.

Coduri de eroare

PDC_4001
Autorizare lipsă. Cheia API nu este prezentă sau are format incorect.
PDC_4003
Plafon depășit. Suma depășește plafonul zilnic al planului de influență. Considerați upgrade sau activarea fracționării.
PDC_4009
Rută neautorizată. Ruta SEAP solicitată nu este disponibilă pe planul curent.
PDC_4022
Justificare respinsă. JustificareAI nu a putut genera o documentație cu rată de acceptare suficientă pentru categoria solicitată.
PDC_5001
SEAP indisponibil. Sistemul Electronic de Achiziții Publice nu răspunde. Reîncercați după 30-60 de minute.
PDC_5009
Tranzacție investigată. Tranzacția a intrat în atenția DNA sau ANAP. Contactați imediat echipa de asistență Demnitar.
PDC_5042
Influență insuficientă. Tranzacția a eșuat din cauza presiunii politice sau opoziției interne. Situație rară, neremediabilă prin API.
